This is Wenxin Chen's personal academic homepage, showcasing research projects, work experience, and photography.

- 📱 响应式设计 | Responsive Design
- 🌐 中英文双语支持 | Bilingual Support (Chinese/English)
- 📸 摄影作品展示 | Photography Gallery
- 🎨 现代简洁的UI设计 | Modern & Clean UI

## 🚀 本地运行 | Local Development

```bash
# 启动本地服务器
python3 -m http.server 8080

# 访问网站
# 打开浏览器访问 http://localhost:8080
```
